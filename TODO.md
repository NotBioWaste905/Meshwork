## Дыры API для нового UI

Новый UI ([docs/design/](docs/design/README.md)) реализован на фронте только в той части, которую
отдаёт API. Фейковых данных во фронте нет: элементы дизайна без бэкенда убраны (экраны входа,
профиля и настроек, шаблоны графов, лог активности, комментарии, ревьюер, фильтр «Mine»).
Ниже — работа на бэкенде, после которой их можно вернуть.

- [ ] Список графов: нет `GET /v0/graphs`. Главная показывает только графы, открытые в этом браузере (`localStorage`)
- [ ] Метаданные графа: у графа нет имени, цели, времени обновления; имя берётся из терминальной задачи
- [ ] Шаблоны графов на экране «New graph» (в дизайне: Software release / Hiring pipeline / Incident response)
- [ ] Авторизация и пользователи: нет входа и текущего пользователя, поэтому нет экрана входа, профиля («My work»), фильтра «Mine» и блока «Waiting on you» на главной. `Task.users` — свободные строки; в шапке графа показываются различные исполнители его задач, исполнитель вводится текстом с подсказками из уже встречающихся имён
- [ ] Участники графа и роли: нет списка членов графа (сейчас аватары в шапке — исполнители задач)
- [ ] Reviewer: нет поля ревьюера; «Approve» / «Send back» на странице задачи просто меняют статус (`REVIEW` → `DONE` / `IN_PROGRESS`) и не проверяют, кто нажал
- [ ] Автор задачи и «Created» — нет `created_by` / `created_at`
- [ ] Лог активности задачи и «Recent activity» (см. «Лог изменений» в фазе 2); колонка «Updated» в таблице и подписи «Updated … ago» на карточках графов не выводятся, нет `updated_at`
- [ ] Комментарии к задаче: нет API, поле комментария убрано
- [ ] Человекочитаемые номера задач (`T-5`): фронт показывает `T-` + первые 4 символа UUID; нужен сквозной счётчик на граф
- [ ] Тип `CHORE`: на фронте это тег `chore` (пунктирная нода, бейдж CHORE); каденса нет
- [ ] Рёбра `PART_OF` и `AFFECTS` в легенде графа приглушены: в модели их ещё нет
- [ ] «Critical path» на графе — клиентский расчёт самой длинной цепочки `DEPENDS_ON`; серверного эндпоинта нет
- [ ] Настройки (профиль, уведомления, участники и роли, API-токены) — нет API, экрана настроек нет
- [ ] Группировка на канбане только по статусу; перетаскивание карточек между колонками не сделано
